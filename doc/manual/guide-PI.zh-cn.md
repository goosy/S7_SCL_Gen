# PI 使用指南

PI 通过 FM350-2 计数模块采集脉冲，计算各通道的瞬时流量和累积流量。每块模块 8 个通道。

- 支持平台：`step7`
- 支持模块：FM350-2
- 生成文件：`PI_Loop.scl`，内含各模块的专用数据块和主循环 `PI_Loop`；另外复制库文件 `PI_Proc.scl`（其中包含 FM350-2 的数据类型 UDT）
- 使用方法：在 OB 中调用 `PI_Loop`

通用指令见 [GCL 配置基础](guide-gcl.zh-cn.md)；完整示例见 [example/PI.yaml](../../example/PI.yaml)。

## 1. 最小示例

```yaml
---
name: AS1-PI

list:
- comment: 1#计量模块
  module: [PI01, IW992]       # 模块硬件地址
  count_DB: [PI01_CNT, DB31]  # FM350-2 专用数据块
  DB: [PI_01, DB+]            # 背景块，存放流量结果
...
```

## 2. 内置符号

| 符号 | 默认地址 | 说明 |
|---|---|---|
| `PI_Proc` | `FB350` | 脉冲处理 FB |
| `PI_Loop` | `FC350` | 主循环函数 |
| `FM350-2` | `UDT350` | FM350-2 专用数据块的数据类型 |

## 3. list 项属性

每个 list 项对应一块 FM350-2 模块。

| 属性 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `DB` | 是 | S7符号定义 \| S7符号引用 | 背景 DB，自动设为 `PI_Proc` 的背景块，存放流量结果 |
| `count_DB` | 是 | S7符号定义 \| S7符号引用 | FM350-2 专用数据块，类型为 `FM350-2` |
| `module` | 二选一 | S7符号定义 \| S7符号引用 | 模块输入地址，如 `IW992` |
| `module_addr` | 二选一 | 正整数 | 模块输入地址的数字部分；会自动定义符号 `PI<序号>_addr` |
| `model` | 否 | 字符串 | 模块型号，目前只支持 `FM350-2`，可省略 |
| `comment` | 否 | 字符串 | 注释 |

`module` 与 `module_addr` 至少提供一个，例如 `module: [PI01, IW992]` 与 `module_addr: 992` 指向同一块模块。

生成的专用数据块中会自动填入：

| 字段 | 值 |
|---|---|
| `MOD_ADR` | 模块地址 |
| `CH_ADR` | 通道地址，即模块地址 × 8 |

## 4. 背景 DB 中的字段

`<n>` 为通道号 1–8：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `equS<n>` | REAL | 10000.0 | 脉冲当量（个/m³） |
| `fix<n>` | REAL | 1.0 | 修正系数 |
| `flow_rate<n>` | REAL | | 瞬时流量（m³/h） |
| `flow<n>` | REAL | | 累积流量（m³），HMI 可修改 |

`equS<n>`、`fix<n>` 没有对应的配置属性，需要在 HMI 或 Step 7 中设置背景 DB 的值。

## 5. 常见错误

| 报错 | 原因 |
|---|---|
| `PI 第n个 module 没有正确定义背景块!` | 缺少 `DB` |
| `PI 第n个模块未提供 module 或 module_addr!` | 两者都没有 |
| `PI 第n个 module 没有正确定义专用数据块!` | 缺少 `count_DB` |
| `PI 的模块(...) 模块地址有误!` | `module` 不是有效的模块地址 |
| `PI: module... 的类型 "..." 不支持` | `model` 不是 `FM350-2` |
| feature 被跳过 | CPU 平台不是 `step7` |
